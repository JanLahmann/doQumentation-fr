Qiskit Functions

Juillet 2026​

  • Nouvelles vérifications préalables et nouvelles méthodes backend dans Qiskit Functions v0.17.0 : de nouvelles méthodes dans qiskit-ibm-catalog te permettent de vérifier la capacité d'exécution et l'accès au backend avant de lancer une exécution, et run() valide désormais les deux avant de soumettre une tâche.

    • Nouveautés

      • Quand tu appelles run() sur une fonction, le service vérifie d'abord trois choses : que ton instance dispose de capacité d'exécution, que tu peux accéder au backend nommé, et qu'au moins un backend est disponible. Si quelque chose ne va pas, tu obtiens immédiatement une erreur claire au lieu d'attendre dans la file d'attente.

        Tu peux aussi vérifier ces ressources toi-même, à tout moment :

        • Vérifie ta capacité d'exécution restante avec usage().

        • Liste les backends auxquels ton instance peut accéder avec backends().

        • Recherche un backend précis et confirme l'accès avec backend().

        • Trouve le backend avec le moins de tâches en attente avec least_busy().

    • Cas d'usage courants

      • Vérifie ta capacité restante avant un long lot de tâches, et n'effectue pas l'exécution s'il n'en reste pas assez pour la terminer.

      • Choisis un backend dans le code plutôt que de coder un nom en dur.

      • Échoue rapidement dans les pipelines et les notebooks plutôt que d'attendre dans la file d'attente.

    • Pour commencer

      • Assure-toi d'abord d'utiliser la dernière version de qiskit-ibm-catalog :

        pip install --upgrade qiskit-ibm-catalog

      • Consulte ensuite la documentation pour plus d'informations et un exemple.

2025​

Troisième trimestre

18 juillet 2025​

Les modèles Qiskit Functions te fournissent un pipeline modulaire qui te permet d'échanger de nouveaux outils, méthodes ou configurations pour tes propres expériences personnalisées. Tous les modèles de fonction sont également facilement déployables sur Qiskit Serverless, où tu peux facilement exploiter le calcul classique dans le cadre de l'exécution de ton workflow. Tu peux déployer ton package serverless dans l'environnement cloud de ton choix, ou profiter du service hébergé fourni par IBM pour les utilisateurs des plans Premium et Flex. Quelle que soit l'option choisie, Qiskit Serverless aide à simplifier l'exécution et à paralléliser des parties de ton workflow.

Consulte le guide Modèles Qiskit Functions pour en savoir plus, ou lis un aperçu de Qiskit Functions dans la documentation.

Deuxième trimestre

5 juin 2025​

  • Nous sommes ravis de lancer deux nouvelles fonctions pour la finance et l'optimisation :

    • QUICK-PDE par ColibriTD permet aux utilisateurs de résoudre certaines équations différentielles pour des problèmes de déformation des matériaux et de dynamique des fluides computationnelle. Par exemple, une équipe de chercheurs a déjà commencé à utiliser la fonction QUICK-PDE pour étudier la dynamique de nouveaux fluides réactifs conçus pour transférer la chaleur plus efficacement dans un type de réacteur nucléaire appelé petit réacteur modulaire (Small Modular Reactor).

    • Quantum Portfolio Optimizer par Global Data Quantum permet aux chercheurs en finance quantitative de rétro-tester des stratégies d'optimisation de portefeuille. Fonctionnant sur plus de 100 qubits, cette fonction calcule le ratio de Sharpe d'un portefeuille par rapport au rendement sur une période donnée. Les premiers utilisateurs explorent la capacité de l'optimiseur à évaluer la performance historique d'une stratégie d'investissement et à permettre la comparaison de différents portefeuilles dans des conditions similaires.

Découvre le catalogue Qiskit Functions pour demander un essai gratuit dès aujourd'hui.

16 mai 2025​

  • Au cours des prochaines semaines, chaque fonction fournira des informations détaillées pour t'aider à exécuter, déboguer et analyser tes workflows. Cela inclut :

    • Quand des tâches échouent, tu peux utiliser job.error_message() pour trouver des codes d'erreur et des messages spécifiques afin de t'aider à déboguer tes workflows

    • job.status() fournira davantage d'informations sur ce qui se passe pendant qu'une fonction est en état RUNNING, notamment :

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • Enfin, une fois qu'une fonction Qiskit est terminée, tu peux inspecter le temps passé à chaque étape avec job.result()['metadata']['resource_usage'], comme dans l'exemple suivant.

Développer pour voir l'exemple de code
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
      },
    }
  }
}

Nous espérons que ces changements faciliteront l'utilisation de Qiskit Functions, et tu peux commencer avec des essais gratuits dans le catalogue dès aujourd'hui.

2024​

16 septembre 2024​

  • Découvre l'aperçu de Qiskit Functions, pour les utilisateurs du plan Premium d'IBM Quantum. Pour commencer, exécute pip install qiskit-ibm-catalog et explore la documentation Qiskit Functions. Avec le client du catalogue Qiskit Functions, tu peux soumettre des charges de travail à des services abstraits conçus pour accélérer ta recherche. Connecte-toi avec tes identifiants IBM Quantum Platform existants.

    L'aperçu du catalogue Qiskit Functions donne accès aux utilisateurs du plan Premium pour explorer les fonctions disponibles, y compris celles écrites par IBM et celles écrites par d'autres membres de notre écosystème. Le catalogue contient deux types de fonctions : les fonctions de circuit et les fonctions d'application.

    • Les fonctions de circuit offrent une interface simplifiée pour l'exécution de circuits. Elles reçoivent en entrée des circuits abstraits et des observables fournis par l'utilisateur, puis gèrent la synthèse, l'optimisation et l'exécution du circuit ISA représentatif. Les fonctions de circuit rassemblent les dernières capacités en matière de transpilation, de suppression d'erreurs et d'atténuation d'erreurs pour rendre accessible une performance de qualité utilitaire dès la sortie de la boîte. Cela permet aux scientifiques computationnels de se concentrer sur la mise en correspondance de leurs problèmes avec des circuits, plutôt que de construire le modèle pour chaque problème à partir de zéro.

    • Les fonctions d'application couvrent des tâches de plus haut niveau, comme l'exploration d'algorithmes et de cas d'usage spécifiques à un domaine. Les développeurs d'entreprise et les data scientists n'ont pas nécessairement les connaissances de base en science de l'information quantique pour travailler avec des circuits, et espèrent plutôt apporter leur connaissance du domaine pour faire progresser les algorithmes et applications quantiques. Avec les fonctions d'application, les utilisateurs peuvent saisir leurs entrées classiques et recevoir des solutions afin de pouvoir plus facilement expérimenter l'intégration du quantique dans leurs workflows spécifiques à leur domaine.

  • Avec le lancement du catalogue Qiskit Functions, les développeurs du plan Premium peuvent explorer la fonction IBM Circuit. La fonction IBM Circuit inclut les dernières extensions de Qiskit alimentées par l'IA pour la synthèse, l'optimisation et l'ordonnancement de circuits, ainsi que des méthodes avancées d'atténuation d'erreurs pour renvoyer les estimations les plus précises possibles avec le matériel d'aujourd'hui.

    Les utilisateurs peuvent acheter des licences pour les fonctions suivantes, fournies par nos partenaires Q-CTRL, QEDMA et Algorithmiq.

  • Fonctions de circuit

    • Q-CTRL publie une fonction de circuit qui applique des techniques de contrôle quantique pilotées par l'IA, avec lesquelles les utilisateurs peuvent passer à l'échelle avec succès pour des problèmes plus grands.

    • Algorithmiq publie une fonction de circuit qui applique le TEM (atténuation d'erreurs par réseau de tenseurs), une méthode d'atténuation d'erreurs permettant d'obtenir des estimateurs avec moins de shots que la méthode PEC (annulation probabiliste des erreurs).

    • QEDMA publie une fonction de circuit qui utilise des protocoles propriétaires pour une caractérisation efficace et précise des opérations bruitées du QPU, et applique la suppression et l'atténuation des erreurs sur la base des données de caractérisation.

  • Fonctions d'application

    • Q-CTRL publie un solveur d'optimisation avec lequel les utilisateurs peuvent transmettre un graphe ou un objectif, et recevoir des coûts de solution.
