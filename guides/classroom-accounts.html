Créer un compte Classroom

Un compte Classroom IBM Quantum® est un moyen simple pour les enseignants de configurer et de gérer l'accès de leurs étudiants au matériel IBM Quantum dans le cadre du Plan Ouvert, sans avoir besoin de renseigner des informations de carte de crédit. Le Plan Ouvert offre 10 minutes d'utilisation d'unité de traitement quantique (QPU) par fenêtre glissante de 28 jours.

Soumettre une demande​

Remplis ce formulaire pour soumettre une demande de compte Classroom.

Les candidats approuvés pour un compte Classroom recevront un e-mail contenant un code de fonctionnalité à 32 chiffres, dont tu auras besoin pendant le processus d'activation ci-dessous.

N'oublie pas de soumettre ton ID de compte

Si ta demande de compte Classroom est approuvée, ne supprime pas l'e-mail de confirmation que tu reçois. En plus du code de fonctionnalité, il contient également des instructions pour renvoyer ton nouvel ID de compte à l'équipe IBM Quantum afin que le compte puisse être activé. Les comptes Classroom ne seront pas activés sans cette dernière étape.

Activer le compte​

Les candidats approuvés pour un compte Classroom recevront un e-mail contenant un code de fonctionnalité à 32 chiffres. Ne supprime pas cet e-mail ; il contient des informations importantes pour soumettre ton nouvel ID de compte une fois que tu as configuré ton compte, ce qui est une étape obligatoire pour finaliser l'activation.

Une fois que tu as un code de fonctionnalité, suis les étapes d'activation ci-dessous :

Ne saisis pas les informations de carte de crédit

Lors de la création d'un compte avec un code de fonctionnalité, ne fournis pas d'informations de carte de crédit sur IBM Cloud® à moins que tu ne sois en train de passer activement à un compte payant et que tu sois prêt à accepter d'être facturé pour les services consommés.

  1. Visite https://cloud.ibm.com/.

  2. Clique sur Créer un compte. Tu dois créer un nouveau compte même si tu as déjà un compte IBM Cloud personnel, car le compte Classroom n'est pas rattaché à ton compte personnel.

  3. Saisis une adresse e-mail valide et un mot de passe. Utilise une adresse e-mail qui n'est pas associée à un compte IBM Cloud existant. Clique sur Suivant.

  4. Vérifie ta boîte de réception pour un code de vérification à sept chiffres, puis retourne sur le formulaire de création de compte. Saisis ce code pour vérifier ton nouveau compte.

  5. Important : Dans la section Informations personnelles, ne saisis pas ton prénom et ton nom. Au lieu de cela, dans le champ « Prénom », saisis ton affiliation institutionnelle, et dans le champ « Nom », saisis le nom du cours utilisant le compte. Saisis ton pays ou ta région.

  6. Complète l'avis relatif au compte et clique sur Continuer.

  7. Complète l'avis de confidentialité du compte et clique sur Continuer.

  8. Sur l'écran de vérification d'identité, clique sur S'enregistrer avec un code.

  9. Saisis ton code de fonctionnalité à 32 chiffres provenant de ton e-mail de confirmation dans la case Entrer le code, puis clique sur Créer un compte.

  10. Accède aux paramètres de ton compte sur IBM Quantum Platform et copie l'ID de compte (trouvé sous Détails).

  11. Suis les instructions figurant dans l'e-mail de confirmation que tu as reçu pour envoyer ce numéro d'ID à l'équipe IBM Quantum, qui traitera le compte Classroom pour une activation complète.

Ajouter des utilisateurs​

  1. Tout d'abord, assure-toi d'avoir sélectionné le bon compte et la bonne région dans les sélecteurs de compte et de région de l'en-tête IBM Quantum Platform.

  2. Sélectionne Gestion des accès dans le menu principal.

  3. Dans l'onglet Utilisateurs, clique sur « Inviter un utilisateur ».

  4. Saisis les adresses e-mail des utilisateurs. Tu peux ajouter plusieurs adresses en même temps.

  5. Par défaut, une instance est attribuée à chaque nouvel utilisateur. Il est recommandé d'accepter le paramètre par défaut.

    Le nom de l'instance sera automatiquement basé sur l'adresse e-mail de l'utilisateur (sans le caractère @ et le nom de domaine). Dans le champ « Schéma de nommage de l'instance », tu peux personnaliser un préfixe pour chaque nom d'instance ; par exemple, si l'adresse e-mail d'un étudiant est john-doe@university.edu, et que tu spécifies physics-101 comme préfixe pour ce compte, le nom de l'instance sera physics-101-john-doe. Si tu ne spécifies pas de préfixe, le préfixe par défaut open-student sera utilisé (open-student-john-doe).

  6. L'utilisateur recevra une invitation à créer un compte IBM Cloud et à rejoindre l'instance. Il n'aura pas besoin de saisir d'informations de carte de crédit pour créer son compte.

  7. Une fois que l'utilisateur a accepté l'invitation et créé son compte, il peut accéder à IBM Quantum Platform, où il verra son instance de compte Classroom dans le sélecteur de compte de l'en-tête de la page.

Supprimer des utilisateurs​

Pour supprimer un utilisateur d'un compte Classroom, suis ces étapes :

  1. Sélectionne Gestion des accès dans le menu principal.

  2. Dans l'onglet Utilisateurs, clique sur le menu à trois points à la fin de la ligne de cet utilisateur.

  3. Sélectionne Supprimer l'utilisateur. Une invite s'affichera pour confirmer que tu souhaites supprimer l'utilisateur du compte. Clique sur Supprimer pour confirmer.

Gérer les instances​

Chaque instance offre jusqu'à 10 minutes d'utilisation de QPU par fenêtre glissante de 28 jours.

En tant que propriétaire du compte Classroom, tu peux consulter toute l'activité de toutes les instances du compte sur la page Analytics.

Les utilisateurs étudiants peuvent voir les données des charges de travail exécutées dans leur propre instance. Ils ne peuvent pas voir les données d'autres instances.

Renouveler le compte Classroom​

Pour renouveler un compte Classroom proche de sa date d'expiration, demande un nouveau code de fonctionnalité à l'aide de ce formulaire de renouvellement.

Prochaines étapes​

Recommandations

Oriente tes étudiants vers la documentation pour plus de détails sur l'utilisation d'IBM Quantum Platform. Les sujets fréquemment utilisés incluent les suivants :

  • Consulter les détails d'un backend
  • Minimiser le temps d'exécution d'un job
  • Organiser et rechercher par étiquettes de job
  • Récupérer et enregistrer les résultats d'un job
  • Surveiller ou annuler un job
