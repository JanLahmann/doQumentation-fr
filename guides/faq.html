Questions fréquentes (FAQ)

Pour les questions fréquentes spécifiques aux modes d'exécution, consulte le guide FAQ sur les modes d'exécution de Qiskit Runtime.

Comment citer Qiskit dans mes recherches ?​

Cite Qiskit en utilisant le fichier BibTeX fourni.

Comment citer un ordinateur IBM Quantum dans mes recherches ?​

Pour les articles de recherche, nous encourageons les auteurs à mentionner IBM Quantum® en utilisant :

Nous reconnaissons l'utilisation des services IBM Quantum pour ce travail. Les opinions exprimées sont celles des auteurs et ne reflètent pas la politique officielle ou la position d'IBM ou de l'équipe IBM Quantum.

Les références bibliographiques doivent utiliser la citation suivante :

IBM Quantum. https://quantum.cloud.ibm.com/, YYYY

Les unités de traitement quantique dans l'article doivent être référencées par leur nom unique (par exemple, ibmq_vigo) en ajoutant éventuellement la version (par exemple, ibmq_vigo v1.0.2). Nous encourageons également à référencer le processeur. Par exemple :

Dans cet article, nous avons utilisé ibmq_vigo, qui est l'un des processeurs IBM Quantum Canary.

Exemple de citation d'un programme IBM Quantum :

IBM Quantum (2025). Estimator primitive (Version x.y.z) [logiciel informatique]. https://quantum.cloud.ibm.com/

Comment citer IBM Quantum Composer dans mes recherches ?​

Exemple de citation pour IBM Quantum Composer :

IBM Quantum Composer. 2025. url : https://quantum.cloud.ibm.com/composer

Je ne vois pas quelque chose dans l'interface utilisateur, comme mes tâches d'administration.​

Essaie de choisir un autre compte depuis le sélecteur de comptes dans l'en-tête de l'interface IBM Quantum Platform.

J'utilise seulement le plan Open, mais j'ai dû entrer ma carte de crédit. Vais-je être facturé(e) ?​

Tu ne seras pas facturé(e) à moins que tu ne crées une instance Pay-As-You-Go et que tu l'utilises pour envoyer des charges de travail aux QPUs. Consulte Gérer les coûts pour obtenir des instructions sur la définition d'une limite de coût et pour en savoir plus sur d'autres façons de gérer les coûts.

Quelle est la différence entre une clé API et un jeton API ?​

Il n'y a aucune différence. Les termes clé API et jeton API sont utilisés de façon interchangeable. Tu verras les deux termes dans la documentation, car différentes interfaces emploient des termes différents.

Quelle est la différence entre un jeton API et un jeton bearer ?​

Un jeton API est un identifiant de longue durée utilisé pour s'authentifier auprès du service Qiskit Runtime. Un jeton bearer est un identifiant temporaire utilisé pour s'authentifier auprès de l'API REST dans un environnement non fiable. Un jeton bearer ne peut pas être utilisé pour s'authentifier auprès du service Qiskit Runtime.

Dois-je choisir la région dans laquelle je vis ?​

Non. Tu peux utiliser l'une ou l'autre des régions. La région détermine où les jobs sont exécutés et où les données sont conservées. De plus, tu ne peux voir et utiliser que les instances créées dans l'instance à laquelle tu es connecté(e). Note que seule la région us-east prend en charge le plan Open.

Puis-je me connecter via un serveur proxy ?​

Oui, mais tu dois utiliser Qiskit Runtime v0.44.0 ou une version ultérieure.

Quelle est la politique de conservation des données ?​

IBM conserve tes données de jobs et d'utilisation (non supprimées) pendant trois ans tant que tu continues à utiliser le service Qiskit Runtime.

Qu'est-il arrivé aux distributions Python telles que Qiskit Aer, Qiskit Nature et Qiskit Experiments ?​

Depuis la sortie du Qiskit SDK v1.0, la commande pip install qiskit n'installera que le Qiskit SDK. Cela signifie que certains modules que tu as utilisés par le passé, tels que qiskit-aer ou qiskit-nature, doivent désormais être installés séparément.

Avant la sortie du Qiskit SDK v1.0, Qiskit était composé de nombreuses distributions Python différentes, telles que qiskit-terra, le cœur du compilateur ; qiskit-aer, le simulateur haute performance ; le fournisseur IBM Quantum® d'origine ; et plusieurs packages désormais obsolètes fournissant des fonctionnalités algorithmiques exploratoires particulières ou d'exécution d'expériences.

Ces packages logiciels distincts ont été regroupés dans ce qu'on appelait le métapackage Qiskit, qui permettait aux utilisateurs d'installer tous ces composants ensemble via pip install qiskit. Cette architecture de métapackage a été supprimée avec la sortie du Qiskit SDK v1.0, et chacune des distributions logicielles individuelles doit maintenant être installée séparément.

Si tu veux installer les packages qui étaient précédemment inclus dans le métapackage Qiskit, visite l'écosystème Qiskit pour trouver une gamme de packages adaptés à tes besoins. Tu peux également lire le guide de migration v1.0 pour plus d'informations sur ce changement.

Comment fermer mon compte IBM Cloud ?​

Trouve les instructions sur la page Fermeture d'un compte.

Pourquoi un message m'indique que mon compte est inactif lorsque j'essaie de me connecter ?​

Si tu vois le message « This account is inactive », consulte la documentation IBM Cloud pour en savoir plus sur les causes possibles et comment y remédier, ou accède à IBM Cloud pour vérifier si des actions en attente sont à effectuer dans ton compte.

Quel est l'impact de la dérive des appareils ?​

L'impact de la dérive des appareils (dégradation des performances matérielles au fil du temps) dépend de nombreux facteurs, tels que la date des dernières calibrations, l'expérience spécifique effectuée, les activités TLS, etc. Si un workload particulier est très sensible aux valeurs d'erreur des paramètres de l'appareil, tu peux effectuer une analyse comparative en temps réel des paramètres de l'appareil en suivant ce tutoriel dans IBM Quantum Learning.
