Résonance magnétique nucléaire avec Qiskit

Pour ce module Qiskit in Classrooms, les étudiants doivent disposer d'un environnement Python fonctionnel avec les packages suivants installés :

  • qiskit v2.1 ou plus récent
  • qiskit-ibm-runtime v0.40.1 ou plus récent
  • qiskit-aer v0.17 ou plus récent
  • scipy et matplotlib (pour l'ajustement et le tracé)
  • pylatexenc (pour le rendu des diagrammes de circuits)

Pour configurer et installer les packages ci-dessus, consulte le guide Installer Qiskit. Pour exécuter des jobs sur de vrais ordinateurs quantiques, les étudiants doivent créer un compte IBM Quantum® en suivant les étapes du guide Configurer ton compte IBM Cloud®.

Ce module a été testé et utilise environ 5 minutes de temps QPU. Il s'agit d'une estimation, et ton utilisation réelle peut varier.

Introduction​

Lorsqu'un chimiste réalise une expérience de RMN, il place un échantillon de spins nucléaires dans un champ magnétique intense, applique une impulsion de radiofréquence (RF) et mesure le signal qui en revient. La technique repose sur quelques idées issues de la mécanique quantique d'une particule de spin 1/2 dans un champ magnétique. Le spin possède deux niveaux d'énergie séparés par une énergie qui correspond à une fréquence de Larmor caractéristique. Une impulsion résonante à cette fréquence bascule le spin dans le plan transverse, où il précesse et induit un signal qui s'atténue ensuite avec deux temps caractéristiques, T1T_1T1​ et T2T_2T2​.

Un qubit supraconducteur est une version conçue du même objet : un système quantique à deux niveaux contrôlable. Ses états ∣0⟩|0\rangle∣0⟩ et ∣1⟩|1\rangle∣1⟩ sont l'analogue du spin haut et du spin bas, la porte que nous appliquons pour le faire tourner est l'analogue de l'impulsion RF, et il perd sa cohérence avec ses propres T1T_1T1​ et T2T_2T2​. Ce n'est pas une simple comparaison approximative ; certains des tout premiers processeurs quantiques expérimentaux de la fin des années 1990 et du début des années 2000 utilisaient la RMN.

Dans ce module, tu vas utiliser un vrai ordinateur quantique pour exécuter les mêmes expériences de caractérisation que celles réalisées par un spectroscopiste RMN (ou un ingénieur quantique qui calibre du matériel) :

  • Rabi / nutation — piloter le spin et le regarder tourner. C'est ainsi que tu calibres une rotation de π\piπ ou π/2\pi/2π/2.

  • T1T_1T1​ — relaxation spin-réseau, le retour d'un spin excité à l'équilibre.

  • T2T_2T2​ — relaxation spin-spin (déphasage), mesurée avec une expérience de Ramsey et refocalisée avec un écho de Hahn.

  • Spectroscopie RMN (déplacement chimique et couplage JJJ) — simuler une petite molécule sur plusieurs qubits et lire son spectre de multiplets pour retrouver la connectivité grâce à la règle n+1n+1n+1.

Pour chaque concept, nous donnons d'abord la théorie minimale, puis nous implémentons l'expérience dans Qiskit en suivant le workflow en quatre étapes des Qiskit patterns.

Théorie​

Particules de spin 1/2 dans un champ magnétique​

Un noyau de spin 1/2 possède un moment magnétique μ=γℏI\boldsymbol{\mu} = \gamma \hbar \mathbf{I}μ=γℏI, où γ\gammaγ est le rapport gyromagnétique. Dans un champ statique B0B_0B0​ selon zzz, les deux états de spin se séparent en énergie (l'effet Zeeman) :

E±=∓12γℏB0,ΔE=γℏB0=ℏω0.E_{\pm} = \mp \tfrac{1}{2}\gamma \hbar B_0, \qquad \Delta E = \gamma \hbar B_0 = \hbar \omega_0 .E±​=∓21​γℏB0​,ΔE=γℏB0​=ℏω0​.

L'écart d'énergie définit la fréquence de Larmor (de résonance) ω0=γB0\omega_0 = \gamma B_0ω0​=γB0​. Le moment magnétique précesse autour de B0B_0B0​ à cette même fréquence.

Pour faire tourner le spin, nous appliquons un champ RF oscillant à ω0\omega_0ω0​ (ou près de ω0\omega_0ω0​). Dans le référentiel tournant à la fréquence de pilotage (le référentiel tournant), un pilotage résonant fait tourner le vecteur de Bloch autour d'un axe du plan xxx-yyy. L'ampleur de la rotation (l'angle de basculement) est fixée par l'intensité et la durée de l'impulsion. Deux choix comptent le plus : une impulsion de 90∘90^\circ90∘ bascule un spin +1/2+1/2+1/2 dans le plan transverse, et une impulsion de 180∘180^\circ180∘ le fait tourner complètement jusqu'à −1/2-1/2−1/2.

Traduire entre le jargon de la RMN et celui de l'informatique quantique​

Un qubit est un système à deux niveaux, mathématiquement identique à un spin 1/2 dans un champ magnétique — donc, même si nous travaillons sur un processeur quantique plutôt que sur un noyau, la physique est la même que celle qui sous-tend la RMN. import numpy as np
from itertools import combinations
from qiskit_aer import AerSimulator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import EstimatorV2 as Estimator

USE_HARDWARE = True  # <-- set True to run on the QPU selected above
USE_BATCH = False  # Safer for a class with pauses; set True for an uninterrupted run

if USE_HARDWARE:
    run_backend = backend  # the real QPU selected above
else:
    # Local testing mode: an Aer simulator that mimics the selected device -- its noise model,
    # coupling map, and qubit count -- while layout choices still use real calibration data.
    run_backend = AerSimulator.from_backend(backend)

# --- Choose connected qubits with low readout error. --------------------------------------
def readout_error(q):
    props = backend.target["measure"].get((q,))
    return props.error if props is not None and props.error is not None else 1.0

coupling_map = backend.coupling_map or backend.target.build_coupling_map()
edges = {tuple(sorted(edge)) for edge in coupling_map.get_edges() if edge[0] != edge[1]}

# AX needs one connected pair.
AX_LAYOUT = list(min(edges, key=lambda edge: sum(readout_error(q) for q in edge)))

# AX2 needs one qubit connected to two neighbours; the first entry is the central A qubit.
neighbors = {q: set() for q in range(backend.num_qubits)}
for q0, q1 in edges:
    neighbors[q0].add(q1)
    neighbors[q1].add(q0)
ax2_layouts = (
    [a, x1, x2]
    for a, adjacent in neighbors.items()
    for x1, x2 in combinations(adjacent, 2)
)
AX2_LAYOUT = min(ax2_layouts, key=lambda layout: sum(readout_error(q) for q in layout))

# Use a long-lived qubit for the single-qubit experiments.
def best_qubit(backend):
    return max(
        range(backend.num_qubits), key=lambda q: backend.qubit_properties(q).t2 or 0.0
    )

QUBIT = best_qubit(backend)
qp = backend.qubit_properties(QUBIT)
print(
    f"Using qubit {QUBIT} for single-qubit experiments: "
    f"T1 = {qp.t1 * 1e6:.0f} us, T2 = {qp.t2 * 1e6:.0f} us"
)
print(f"Using physical qubits {AX_LAYOUT} for AX")
print(f"Using physical qubits {AX2_LAYOUT} for AX2 (A first, then the two X spins)")

pm_q = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=[QUBIT]
)
pm_ax = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX_LAYOUT
)
pm_ax2 = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX2_LAYOUT
)

# Job mode is the default because a classroom pause can deactivate a Batch. On the Open plan,
# a Batch has a 10-minute maximum lifetime and deactivates after 1 minute with no queued job.
batch = Batch(backend=run_backend) if USE_BATCH else None
execution_mode = batch if batch is not None else run_backend
sampler = Sampler(mode=execution_mode)
estimator = Estimator(mode=execution_mode)
estimator.options.resilience_level = 0  # raw expectation values, no error mitigation
estimator.options.default_shots = 1000

mode_name = "Batch" if USE_BATCH else "individual jobs"
device_name = "hardware" if USE_HARDWARE else "local simulator (runtime local mode)"
print(f"Ready. Running on {device_name} using {mode_name}.")

Expérience : oscillations de Rabi (nutation)​

Théorie​

Pilote un spin à la résonance et son vecteur de Bloch tourne régulièrement d'un pôle à l'autre — il nute. Si nous appliquons une rotation d'angle de basculement θ\thetaθ autour de l'axe xxx à un qubit initialement dans ∣0⟩|0\rangle∣0⟩, la probabilité de le trouver dans ∣1⟩|1\rangle∣1⟩ est :

P1(θ)=sin⁡2 ⁣(θ2)=12(1−cos⁡θ).P_1(\theta) = \sin^2\!\left(\tfrac{\theta}{2}\right) = \tfrac{1}{2}\bigl(1 - \cos\theta\bigr).P1​(θ)=sin2(2θ​)=21​(1−cosθ).

C'est la courbe de Rabi. Son premier maximum correspond à l'impulsion π\piπ (inversion complète, l'impulsion de 180∘180^\circ180∘) ; une impulsion π/2\pi/2π/2 est un quart de tour (l'impulsion de 90∘90^\circ90∘ qui bascule un spin dans le plan transverse). En RMN, cette courbe sert à calibrer tes impulsions.

Réserve expérimentale

Une expérience de Rabi littérale balaie l'amplitude ou la durée du pilotage dans le temps. Cela nécessite un contrôle au niveau des impulsions, qui a été supprimé dans Qiskit v2.0. Ici, nous balayons à la place l'angle de rotation θ\thetaθ d'une porte RX(θ)R_X(\theta)RX​(θ). La courbe et l'identification de π\piπ/π/2\pi/2π/2 sont identiques ; la seule différence est que nous choisissons directement un angle au lieu de calibrer une durée d'impulsion. Sur du matériel avec des portes fractionnaires, RX(θ)R_X(\theta)RX​(θ) s'exécute nativement pour un θ\thetaθ arbitraire.

Une vue sur la sphère de Bloch​

L'animation ci-dessous montre la nutation : une impulsion résonante fait tourner régulièrement le vecteur de Bloch autour de l'axe xxx, le faisant passer de ∣0⟩|0\rangle∣0⟩ vers ∣1⟩|1\rangle∣1⟩ puis revenir. C'est exactement le mouvement que mesure la courbe de Rabi.

Associer le problème à un circuit​

Nous construisons un circuit paramétré, RX(θ)R_X(\theta)RX​(θ) suivi d'une mesure, puis nous l'évaluons ensuite pour de nombreux angles à la fois.

Vérifie ta compréhension​

Sur la courbe que tu as mesurée, P1P_1P1​ atteint son maximum pour la première fois à l'impulsion π\piπ (θ=π\theta = \piθ=π). Suppose maintenant qu'un appareil soit mal calibré, de sorte qu'un angle nominal θ\thetaθ sur l'axe des x produise en réalité une rotation de 1.05 θ1.05\,\theta1.05θ.

(a) À quel angle nominal le premier maximum de P1P_1P1​ apparaîtrait-il maintenant ? (b) Appliquer une seule impulsion π\piπ serait-il un moyen sensible de détecter cette erreur de 5 % ?

Réponse

(a) Le maximum apparaît là où la rotation réelle est égale à π\piπ, c'est-à-dire à l'angle nominal θ=π/1.05≈0.95π\theta = \pi/1.05 \approx 0.95\piθ=π/1.05≈0.95π — un léger décalage du pic vers la gauche.

(b) Non. Une impulsion π\piπ nominale produit une rotation réelle de 1.05π1.05\pi1.05π, ce qui donne P1=sin⁡2(1.05π/2)≈0.994P_1 = \sin^2(1.05\pi/2) \approx 0.994P1​=sin2(1.05π/2)≈0.994 au lieu de 111 — une variation trop petite pour être visible face au bruit de mesure. C'est pourquoi, pour calibrer précisément, les spectroscopistes RMN amplifient l'erreur en appliquant la rotation de nombreuses fois (par exemple la méthode 360∘360^\circ360∘, ou un long train d'impulsions), de sorte qu'une petite erreur par impulsion s'accumule en un écart important et mesurable. Nous revenons sur cette idée dans les problèmes de défi.

Expérience : T1T_1T1​ (relaxation spin-réseau)​

Théorie​

Laissé à lui-même, un spin excité cède de l'énergie à son environnement (le « réseau ») et relaxe vers l'équilibre thermique. La population de l'état excité décroît de façon exponentielle avec le temps de relaxation spin-réseau T1T_1T1​ :

P1(τ)=e−τ/T1.P_1(\tau) = e^{-\tau/T_1}.P1​(τ)=e−τ/T1​.

Pour un chimiste, T1T_1T1​ fixe le délai de récupération à attendre entre deux scans pour une RMN quantitative, et il renseigne sur la rotation moléculaire et la dynamique. Pour un qubit, c'est le temps de relaxation de l'énergie, et c'est l'un des deux principaux nombres utilisés pour modéliser les effets de décohérence dans un ordinateur quantique.

L'expérience. Prépare ∣1⟩|1\rangle∣1⟩ avec une porte XXX (une impulsion π\piπ), attends un délai variable τ\tauτ, puis mesure. La fraction encore dans ∣1⟩|1\rangle∣1⟩ dessine la décroissance.

Une vue sur la sphère de Bloch​

La relaxation T1T_1T1​ ramène l'état excité à l'équilibre, de sorte que le vecteur de Bloch glisse de ∣1⟩|1\rangle∣1⟩ vers ∣0⟩|0\rangle∣0⟩ le long de l'axe zzz.

Construire et transpiler un balayage de délais​

Les durées de délai doivent être des valeurs concrètes (elles sont planifiées en temps matériel), nous construisons donc un circuit par délai.

# Scale the T1 delay sweep to the qubit's reported coherence, and snap each delay to an integer
# number of samples (dt) so there are no "duration rounded" warnings (as in the Ramsey/echo cells).
T1_us = (backend.qubit_properties(QUBIT).t1 or 100e-6) * 1e6  # reported T1 (us)
delays_us = np.linspace(0, 5 * T1_us, 20)  # 0 .. ~5 T1 captures the full decay
print(f"T1 sweep: 0..{5*T1_us:.0f} us in {len(delays_us)} points")

dt = backend.dt
t1_circuits = []
for tau in delays_us:
    n_dt = int(round(tau * 1e-6 / dt))  # integer samples -> no rounding warning
    qc = QuantumCircuit(1, 1)
    qc.x(0)  # pi pulse: prepare |1>
    qc.delay(n_dt, 0, unit="dt")  # wait tau
    qc.measure(0, 0)
    t1_circuits.append(qc)

t1_isa = pm_q.run(t1_circuits)

Exécuter​

t1_job = sampler.run([(c,) for c in t1_isa], shots=1000)

Analyser : ajuster l'exponentielle​

from scipy.optimize import curve_fit

p1_t1 = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in t1_res]
)

def decay(t, A, T1, B):
    return A * np.exp(-t / T1) + B

p0 = [1.0, 100.0, 0.0]
popt, _ = curve_fit(decay, delays_us, p1_t1, p0=p0, maxfev=10000)
T1_fit = popt[1]

plt.figure(figsize=(7, 4))
plt.plot(delays_us, p1_t1, "o", label="measured")
tt = np.linspace(0, delays_us.max(), 200)
plt.plot(tt, decay(tt, *popt), "-", label=rf"fit: $T_1$ = {T1_fit:.1f} µs")
plt.xlabel("delay τ (µs)")
plt.ylabel(r"$P_1$")
plt.title("$T_1$ relaxation")
plt.legend()
plt.tight_layout()
plt.show()
print(f"Measured T1 = {T1_fit:.1f} microseconds")

Expérience : T2T_2T2​, T2∗T_2^*T2∗​​

Théorie​

T1T_1T1​ mesure la perte d'énergie. T2T_2T2​ mesure la perte de cohérence de phase dans le plan transversal. Nous pouvons l'observer avec une expérience de Ramsey : une impulsion π/2\pi/2π/2 fait basculer tous les spins à l'équateur, tous orientés dans la même direction. Ils précessent à la fréquence de Larmor, mais chacun précesse à une fréquence légèrement différente, si bien qu'ils s'étalent le long de l'équateur et que le signal transversal net décroît, avec un temps de décroissance caractéristique T2∗T_2^*T2∗​.

Remarque pour les lecteurs en informatique quantique : l'image de l'étalement montre une façon de perdre la cohérence : une dispersion de phases définies qui se moyennent. Il faut savoir que ce n'est pas le seul mécanisme. La cohérence peut aussi se perdre parce que la phase s'intrique avec l'environnement, de sorte qu'elle n'est plus du tout une valeur définie que le système possède. On ne peut pas distinguer les deux mécanismes en observant simplement la décroissance du signal ; l'image de l'étalement est donc une bonne intuition. Prends garde à ne pas la lire comme l'histoire complète ou littérale.

Deux effets déphasent un spin :

  • Une décohérence irréversible (ou effectivement irréversible) provenant d'un couplage non contrôlé à d'autres degrés de liberté, caractérisée par le véritable T2T_2T2​. En RMN, elle vient généralement du mouvement moléculaire qui module les couplages entre spins. En informatique quantique, elle correspond aux couplages indésirables entre les qubits et l'environnement.
  • Des décalages de fréquence réversibles, statiques ou lentement variables, comme l'inhomogénéité du champ, la variation de fréquence d'un qubit à l'autre et les erreurs de calibration. Combinés au véritable T2T_2T2​, ils produisent le temps de décroissance apparent plus court T2∗T_2^*T2∗​ observé dans une expérience de Ramsey.

Alors, comment retrouver le véritable T2T_2T2​ si une expérience de Ramsey ne nous renseigne que sur T2∗T_2^*T2∗​ ? La seconde expérience, appelée écho de Hahn, annule tout le bruit du second type pour trouver le véritable T2T_2T2​. Elle commence comme une expérience de Ramsey, avec une impulsion π/2\pi/2π/2, puis les spins s'étalent comme avant. Après un temps τ\tauτ, une impulsion π\piπ est appliquée. Elle inverse l'accumulation de phase causée par les décalages de fréquence statiques, de sorte que les spins se refocalisent après un second délai de même durée, τ\tauτ.

T2∗T_2^*T2∗​ et T2T_2T2​ sont deux nombres importants à connaître, aussi bien en chimie qu'en informatique quantique. En chimie, T2∗T_2^*T2∗​ fixe la largeur de raie d'une expérience RMN standard (tu verras ce que cela signifie dans une section ultérieure). T2T_2T2​ peut en dire long sur les molécules, comme leur rotation moléculaire, et un changement de T2T_2T2​ peut signaler qu'une molécule s'est liée à quelque chose de plus grand. En informatique quantique, nous voulons généralement que T2T_2T2​ et T2∗T_2^*T2∗​ soient aussi longs que possible, afin d'avoir plus de temps pour réaliser des expériences avant que la décohérence ne submerge le système. Toute une famille de techniques fondées sur l'écho de Hahn prolonge ce temps en annulant le bruit réversible, de sorte que le circuit soit idéalement limité par le véritable T2T_2T2​, et non par T2∗T_2^*T2∗​. C'est ce qu'on appelle le « découplage dynamique ».

Implémentation​

Quand nous implémentons les expériences de Ramsey et d'écho de Hahn sur un qubit, la lecture est légèrement différente du cas de la RMN. En RMN, tu peux observer directement les champs oscillants induits par les spins qui précessent à la fréquence de Larmor dans le plan transversal. Mais avec un qubit, nous ne pouvons mesurer que sa projection selon l'axe ZZZ, c'est-à-dire s'il est ∣0⟩\vert 0 \rangle∣0⟩ ou ∣1⟩\vert 1 \rangle∣1⟩. Pour les deux expériences, nous terminons donc par une impulsion π/2\pi/2π/2 supplémentaire suivie d'une mesure. Cette impulsion π/2\pi/2π/2 traduit l'information de phase du qubit en une population.

Ci-dessous, nous exécutons chaque expérience pour déterminer T2∗T_2^*T2∗​ et T2T_2T2​.

Ramsey (T2∗T_2^{*}T2∗​) : deux impulsions π/2\pi/2π/2 avec un délai τ\tauτ​

La première impulsion π/2\pi/2π/2 bascule le vecteur de Bloch à l'équateur, et la suivante traduit la phase du vecteur de Bloch en population. Comme la phase change au cours du temps pendant la précession du vecteur de Bloch, nous voyons un motif sinusoïdal dans la population en fonction du temps de précession τ\tauτ. À mesure que le qubit perd sa cohérence de phase, nous devrions voir l'amplitude de cette sinusoïde décroître.

Quelques subtilités de plus pour les lecteurs en informatique quantique : dans les expériences d'informatique quantique, les oscillations que nous voyons ne sont pas réellement à la fréquence de Larmor, qui est de l'ordre du GHz et beaucoup trop rapide pour être résolue. Les expériences quantiques se placent dans le référentiel tournant : un référentiel qui tourne avec le qubit à (presque) la fréquence de Larmor, de sorte que la précession rapide est invisible et que le vecteur de Bloch paraît presque immobile. Pour voir des franges, nous désaccordons volontairement un peu notre référentiel tournant par rapport à la fréquence de Larmor. Le vecteur de Bloch semble alors précesser à ce petit désaccord, et nous obtenons un signal oscillant à la fréquence de désaccord. Ci-dessous, nous ne fixons pas le désaccord à une valeur unique ; nous le choisissons de sorte qu'environ une douzaine de franges couvrent la fenêtre de mesure (que nous dimensionnons selon le temps de cohérence du qubit), ce qui permet d'échantillonner facilement l'oscillation sans repliement. Une autre complication : dans Qiskit, nous n'avons pas le contrôle au niveau des impulsions nécessaire pour changer la fréquence de l'impulsion (qui fixe la fréquence du référentiel tournant). À la place, nous ajoutons à la main un désaccord effectif, en l'utilisant pour fixer la phase de la seconde impulsion de Ramsey. C'est un peu artificiel, mais le résultat est le même et la décroissance que nous observons reste bien le véritable T2∗T_2^*T2∗​.

Une vue sur la sphère de Bloch​

Une impulsion π/2\pi/2π/2 bascule les spins à l'équateur ; chacun précesse ensuite à une vitesse légèrement différente et ils s'étalent, de sorte que le vecteur net (rouge) rétrécit à mesure qu'ils se déphasent — cette décroissance est T2∗T_2^*T2∗​.

# Adaptive Ramsey: scale the window to the reported coherence and choose the detuning so a fixed
# number of fringes span it. This decouples the point count from the window -- a long window stays

samp_per_fringe = 8
n_ramsey = n_fringes * samp_per_fringe + 1  # ~97 points, fixed regardless of T2

Écho de Hahn (T2T_2T2​) : ajouter une impulsion π\piπ de refocalisation au milieu​

Une vue sur la sphère de Bloch​

L'écho de Hahn : les spins s'étalent comme avant, puis une impulsion π\piπ les retourne, de sorte que leur précession continue les refocalise ensemble (le vecteur rouge regrandit), récupérant la cohérence perdue à cause du déphasage statique.

Spectroscopie RMN d'une molécule : déplacement chimique et couplage JJJ​

D'un spin à une molécule​

Les expériences jusqu'ici caractérisaient un seul spin isolé. La RMN chimique réelle lit une molécule (de nombreux spins couplés à la fois) et utilise le spectre obtenu pour en déduire des caractéristiques de la structure de la molécule. Cela peut nous renseigner sur deux effets :

  • Déplacement chimique. Chaque noyau chimiquement distinct précesse à une fréquence νi\nu_iνi​ légèrement différente, parce que ses électrons locaux blindent le champ appliqué de façon différente. Les positions des pics identifient donc les environnements chimiques (un proton CH3_33​ par rapport à un proton aromatique, par exemple).

  • Couplage scalaire JJJ. Une interaction à travers les liaisons entre deux spins scinde chaque pic en un multiplet. Un noyau ayant nnn voisins équivalents est scindé en n+1n+1n+1 raies d'intensités binomiales, la règle des n+1n+1n+1. Le motif de scission révèle la connectivité (quels noyaux sont liés), et l'espacement est la constante de couplage JJJ.

L'expérience​

Pour modéliser cela sur notre ordinateur quantique, nous devons implémenter un hamiltonien de spin sur les qubits. Dans la limite de couplage faible et de champ fort (différences de déplacement chimique ≫\gg≫ couplages), les parties XXXXXX et YYYYYY du couplage se moyennent à zéro, ne laissant que ZZZZZZ. L'hamiltonien est donc (en unités de pulsation, ℏ=1\hbar=1ℏ=1) :

H=∑iπ νi Zi⏟chemical shift  +  ∑i<jπ2 Jij ZiZj⏟J-coupling.H = \underbrace{\sum_i \pi\,\nu_i\, Z_i}_{\text{chemical shift}} \;+\; \underbrace{\sum_{i<j} \tfrac{\pi}{2}\,J_{ij}\, Z_iZ_j}_{J\text{-coupling}}.H=chemical shifti∑​πνi​Zi​​​+J-couplingi<j∑​2π​Jij​Zi​Zj​​​.

Chaque noyau est un qubit : le déplacement chimique est une rotation ZZZ à un qubit, et le couplage est une interaction ZZZZZZ à deux qubits.

L'expérience se déroule ainsi. Une impulsion π/2\pi/2π/2 bascule chaque spin dans le plan transversal, et les spins précessent et se couplent pendant un temps ttt. Nous enregistrons l'aimantation transversale complexe s(t)=⟨X⟩+i⟨Y⟩s(t) = \langle X\rangle + i\langle Y\rangles(t)=⟨X⟩+i⟨Y⟩ sommée sur tous les spins. Comme dans l'expérience de Ramsey ci-dessus, cette aimantation transversale dessine une sinusoïde décroissante en fonction du temps de précession ttt. Quand nous prenons la transformée de Fourier du signal, nous obtenons un spectre avec des pics au déplacement chimique νi\nu_iνi​ scindés par le couplage scalaire JijJ_{ij}Jij​.

remarque

Nous simulons l'évolution de la molécule en associant le temps ttt à des angles de rotation : un ttt plus grand signifie des rotations ZZZ et ZZZZZZ plus grandes, et non un circuit plus long ou plus profond. Ainsi, bien que l'état simulé avance avec ttt (c'est ce qui fait osciller la décroissance libre d'induction (FID)), les qubits physiques n'attendent jamais plus longtemps et il n'y a pas de décohérence dépendant de ttt. La FID simulée ne décroît donc jamais d'elle-même. Pour une FID idéale infiniment longue, les raies spectrales seraient infiniment fines ; notre fenêtre d'échantillonnage finie leur donne à la place une résolution finie et peut introduire une fuite spectrale. Les raies RMN réelles ont une largeur finie fixée par T2∗T_2^*T2∗​. Nous la rajoutons en multipliant la FID par une fenêtre e−t/T2∗e^{-t/T_2^{*}}e−t/T2∗​ avant la transformée de Fourier. C'est ce qu'on appelle une apodisation d'élargissement de raie, que les spectroscopistes appliquent lors du traitement pour fixer la largeur de raie (en échangeant de la résolution contre du rapport signal sur bruit). (Une cellule optionnelle dans l'annexe de ce module présente une alternative trotterisée, où la décroissance provient plutôt d'une vraie décohérence qui croît avec la profondeur du circuit.)

Le système AX​

Commençons par ce qu'on appelle le système AX, une molécule constituée de deux spins couplés et chimiquement distincts. Les étiquettes A et X désignent les deux environnements de spin chimiquement distincts. Les lettres sont arbitraires, mais le fait qu'elles soient éloignées dans l'alphabet illustre leur dissemblance chimique.

Associer et optimiser​

Nous écrivons une fonction qui, à partir des décalages de déplacement chimique νi\nu_iνi​ et des couplages JijJ_{ij}Jij​, renvoie un circuit de préparation d'état paramétré. L'impulsion π/2\pi/2π/2 bascule les spins à l'équateur, puis les rotations ZZZ simulent l'évolution de l'état sous les termes de déplacement chimique et de couplage JJJ. Chaque νi\nu_iνi​ est un petit décalage de précession en Hz par rapport à une référence choisie, ou porteuse du référentiel tournant. Ici, nous le fixons manuellement ; dans une vraie molécule, le blindage électronique modifie le champ magnétique local et décale la résonance de chaque noyau par rapport à cette référence. Cela est modélisé par les portes RZR_ZRZ​ à un qubit, une par spin, et chaque νi\nu_iνi​ fixe l'endroit où se situe le pic de ce spin dans le spectre. La porte ZZZZZZ à deux qubits applique le couplage JijJ_{ij}Jij​, qui scinde chaque pic en un multiplet et fixe l'espacement entre ses raies.

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import SparsePauliOp

t = Parameter(
    "t"
)  # evolution time (arbitrary units; the frequencies below are in matching units)

def fid_circuit(offsets, couplings):
    """State-preparation circuit for a set of spins: a pi/2 pulse, then evolution under the
    chemical-shift + J-coupling Hamiltonian for time t. No measurement -- the Estimator reads
    <X> and <Y> directly.

    offsets   : list of chemical-shift frequencies nu_i, one per qubit
    couplings : dict {(i, j): J_ij}
    """
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # pi/2 pulse: tip every spin into the transverse plane
    for i, nu in enumerate(offsets):
        qc.rz(2 * np.pi * nu * t, i)  # chemical-shift precession -> line at nu_i
    for (i, j), J in couplings.items():
        qc.rzz(np.pi * J * t, i, j)  # J-coupling -> splitting of size J
    return qc

def transverse_obs(n):
    """Total transverse observables (sum over spins): (sum_i X_i, sum_i Y_i)."""
    ox = SparsePauliOp.from_sparse_list(
        [("X", [i], 1.0) for i in range(n)], num_qubits=n
    )
    oy = SparsePauliOp.from_sparse_list(
        [("Y", [i], 1.0) for i in range(n)], num_qubits=n
    )
    return ox, oy

# AX system: two distinct chemical shifts, one coupling
ax_offsets = [6.0, -6.0]  # chemical shifts nu_1, nu_2 (Hz)
ax_couplings = {(0, 1): 2.0}  # J_12 = 2 Hz

ax_isa = pm_ax.run(fid_circuit(ax_offsets, ax_couplings))

Nous évaluons le circuit sur une grille de temps d'évolution, et l'Estimator renvoie ⟨X⟩\langle X\rangle⟨X⟩ et ⟨Y⟩\langle Y\rangle⟨Y⟩ pour chacun. Nous les combinons en la FID complexe ⟨X⟩+i⟨Y⟩\langle X\rangle + i\langle Y\rangle⟨X⟩+i⟨Y⟩, appliquons la fenêtre d'apodisation et effectuons la transformée de Fourier du résultat pour obtenir le spectre.

# --- time grid ---

# --- Step 3-4: Estimator returns <X> and <Y> directly (both quadratures in one job) ---
def run_fid(isa_circ, n, est):
    """Complex FID s(t) = sum_i <X_i> + i <Y_i> over the time grid, via the Estimator."""
    ox, oy = transverse_obs(n)
    ox = ox.apply_layout(isa_circ.layout)  # map observables onto the transpiled qubits
    oy = oy.apply_layout(isa_circ.layout)
    params = times.reshape(-1, 1)
    res = est.run(
        [(isa_circ, ox, params), (isa_circ, oy, params)]
    ).result()  # both quadratures, one job
    return res[0].data.evs + 1j * res[1].data.evs

Extension : un système AX2_22​ et la règle des n+1n+1n+1​

Ajoutons maintenant un second voisin équivalent. Dans un système AX2_22​, un spin A se couple, avec le même JJJ, à deux spins X équivalents. (Rappelle-toi que X n'est qu'une étiquette pour les deux spins équivalents ; elle n'a rien à voir avec les opérateurs de Pauli XXX. Tous les couplages ci-dessous restent ZZZZZZ.) Le spin A voit alors quatre configurations de voisins (↑↑, ↑↓, ↓↑, ↓↓)(\uparrow\uparrow,\ \uparrow\downarrow,\ \downarrow\uparrow,\ \downarrow\downarrow)(↑↑, ↑↓, ↓↑, ↓↓) ; les deux configurations mixtes coïncident, donc A est scindé en un triplet 1:2:1 (n=2⇒n+1=3n=2 \Rightarrow n+1 = 3n=2⇒n+1=3 raies). Chaque spin X ne voit que A et reste un doublet. Les spins équivalents ne se scindent pas entre eux, nous n'incluons donc aucun couplage X–X.

Une vraie molécule présentant ce motif est le 1,1,2-trichloroéthane (Cl2_22​CH–CH2_22​Cl). Lorsqu'on cible les spins de l'hydrogène (la forme de RMN la plus courante), l'unique proton d'hydrogène du groupe CH joue le rôle de A, et les deux protons équivalents de CH2_22​ sont les deux spins X. Il suffit maintenant de compter les voisins : le proton CH a deux voisins (la paire CH2_22​), son signal est donc scindé en un triplet 1:2:1 (n=2n=2n=2) ; chaque proton CH2_22​ n'a qu'un voisin (le CH), le signal de CH2_22​ est donc un doublet 1:1 (n=1n=1n=1). Remarque que le groupe ayant moins de protons (CH) montre plus de raies ; le nombre de raies reflète combien de voisins a un signal, et non combien de protons le partagent.

Dans le spectre AX, les deux doublets sont séparés (centre à centre) de 12 Hz, et les deux raies de chaque doublet sont distantes de 2 Hz. Quel nombre est la différence de déplacement chimique et lequel est la constante de couplage JJJ ? Si tu passais à un spectromètre avec un champ magnétique deux fois plus fort, lequel changerait ?

Réponse

La séparation de 12 Hz centre à centre est la différence de déplacement chimique (ν1−ν2\nu_1-\nu_2ν1​−ν2​) ; l'espacement de 2 Hz entre raies est la constante de couplage JJJ. Les déplacements chimiques proviennent du blindage de B0B_0B0​, ils varient donc avec le champ. Avec un champ deux fois plus fort, la séparation double et passe à 24 Hz. Le couplage JJJ est une propriété moléculaire à travers les liaisons et est indépendant du champ, il reste donc à 2 Hz. Les chimistes distinguent le déplacement du couplage en observant comment une scission varie avec le champ.

En utilisant la règle des n+1n+1n+1, prédis le multiplet de A si l'on ajoutait un troisième spin X équivalent (un système AX3_33​), et explique pourquoi les deux spins X équivalents de AX2_22​ ne se scindent pas mutuellement.

Réponse

Avec n=3n=3n=3 voisins équivalents, A devient un quadruplet 1:3:3:1. Les spins équivalents ne se scindent pas entre eux parce que leur couplage décale tous les niveaux d'énergie concernés de la même quantité, de sorte que les écarts entre ces niveaux — les fréquences que nous voyons — ne changent pas.

Conclusion​

Nous avons utilisé un vrai ordinateur quantique pour explorer comment les spins nucléaires précessent et se décohèrent dans une expérience de RMN, et comment interpréter les spectres obtenus. Il vaut la peine de prendre du recul pour revoir pourquoi cela était possible, et pourquoi c'est plus qu'une simple curiosité.

Un qubit et un noyau de spin 1/2 sont, mathématiquement, le même objet : des systèmes quantiques à deux niveaux vivant sur la sphère de Bloch, mis en rotation par des impulsions résonantes, précessant autour d'un axe et perdant leur cohérence au contact de leur environnement. Tout le vocabulaire de ce module (la fréquence de Larmor, le référentiel tournant, T1T_1T1​, T2T_2T2​ et T2∗T_2^*T2∗​, les franges de Ramsey, l'écho de Hahn) appartient autant à la RMN qu'à l'informatique quantique. Ce qu'un chimiste appelle un déplacement chimique, un ingénieur quantique l'appelle une rotation ZZZ à un qubit ; ce qu'un chimiste appelle un couplage JJJ, un ingénieur quantique l'appelle une interaction ZZZZZZ. Les deux domaines décrivent la même physique avec des mots différents.

Ce lien est historique, pas seulement conceptuel : la RMN a été l'une des premières plateformes à exécuter de vrais algorithmes quantiques. En 2001, une molécule en solution avait exécuté l'algorithme de Shor pour factoriser 15, chaque spin nucléaire servant de qubit. La RMN a aussi légué à l'informatique quantique une grande partie de sa boîte à outils de contrôle. L'écho de spin, les trains d'impulsions CPMG, les impulsions composites et le découplage dynamique ont tous été inventés par des spectroscopistes des décennies avant que les qubits n'en aient besoin pour lutter contre la décohérence. Il y a une symétrie satisfaisante dans ce que nous venons de faire : le domaine qui a donné naissance aux premiers ordinateurs quantiques est maintenant quelque chose qu'un ordinateur quantique peut simuler.

Concepts essentiels​

  • Un qubit est un système à deux niveaux conçu, équivalent à un spin 1/2 ; ses ∣0⟩/∣1⟩|0\rangle/|1\rangle∣0⟩/∣1⟩, sa fréquence, ses portes, T1T_1T1​ et T2T_2T2​ sont les analogues directs des grandeurs de la RMN.

  • Une impulsion résonante fait tourner le vecteur de Bloch ; l'angle de bascule fixe la rotation, et la courbe de Rabi/nutation P1=sin⁡2(θ/2)P_1=\sin^2(\theta/2)P1​=sin2(θ/2) identifie les rotations π\piπ et π/2\pi/2π/2.

  • T1T_1T1​ est la relaxation de l'énergie (spin-réseau) ; T2T_2T2​ est la relaxation de la phase (spin-spin) ; T2∗T_2^{*}T2∗​ inclut en plus le déphasage statique réversible qu'un écho de Hahn refocalise.

  • Une molécule est un ensemble de spins couplés : le déplacement chimique fixe la position de chaque pic, et le couplage JJJ scinde les pics en multiplets selon la règle des n+1n+1n+1, ce qui encode ensemble l'environnement chimique et la connectivité.

Annexe (optionnelle) : évolution trotterisée — laisser la décohérence fixer la largeur de raie​

Dans la section Spectroscopie RMN d'une molécule, l'évolution e−iHte^{-iHt}e−iHt est appliquée en une seule couche dont la profondeur ne croît pas avec ttt, de sorte que la FID ne décroît pas d'elle-même et nous imposons la largeur de raie avec la fenêtre d'apodisation e−t/T2e^{-t/T_2}e−t/T2​. Cette cellule optionnelle adopte l'approche opposée. Elle découpe l'évolution en ppp pas de Trotter et place une barrière après chaque pas (pour que le transpiler ne puisse pas les refusionner en une seule couche). Le point temporel kkk utilise kkk pas, de sorte que la profondeur du circuit croît avec le temps.

Comme tous les termes de HHH commutent, c'est exact : sur un simulateur sans bruit, cela donne les mêmes pics fins. Mais sur un backend à modèle de bruit ou du vrai matériel, l'erreur de porte qui s'accumule fait décroître la FID d'elle-même, et c'est cette décroissance qui fixe la largeur de raie. C'est l'idée T2↔T_2\leftrightarrowT2​↔largeur de raie de la section de l'expérience T2T_2T2​, T2∗T_2^*T2∗​, qui provient maintenant d'une vraie décohérence plutôt que d'une fenêtre de traitement. Nous exécutons de cette façon à la fois le système AX (deux doublets) et le système AX2_22​ (un triplet 1:2:1 plus un doublet).

Deux remarques pratiques à prendre en compte. D'abord, le coût est la profondeur : le circuit AX le plus profond utilise ∼ ⁣47\sim\!47∼47 portes à deux qubits et la version AX2_22​ environ le double, les deux sont donc bien plus bruités et coûteux que la version exacte. Ensuite, chaque système de spins est toujours soumis comme un seul job, et chaque point temporel réutilise la même disposition de qubits physiques sélectionnée dans la section de spectroscopie. # Trotterized FID: depth grows with time, so real decoherence (not apodization) sets the linewidth.
estimator.options.default_shots = 2000  # deep circuits need more shots in this appendix
n_tr, dt_tr = (
    48,
    1 / 20,
)  # Nyquist = 1/(2 dt) = 10 Hz (covers the AX2 triplet's 8 Hz line)
times_tr = np.arange(n_tr) * dt_tr
APODIZE_TROTTER = False  # keep False so the linewidth comes from decoherence

def trotter_fid_circuit(offsets, couplings, p, step):
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # 90-degree pulse
    for _ in range(p):  # p Trotter steps, each of duration `step`
        for i, nu in enumerate(offsets):
            qc.rz(2 * np.pi * nu * step, i)  # chemical-shift evolution for one step
        for (i, j), J in couplings.items():
            qc.rzz(np.pi * J * step, i, j)  # J-coupling evolution for one step
        qc.barrier()  # <-- stops the transpiler merging the steps
    return qc

def run_trotter(offsets, couplings, n, est, pass_manager):
    # Time point k uses k Trotter steps (its own circuit). Submit every time point and both
    # quadratures together as ONE Estimator job, using one fixed physical-qubit layout.
    ox, oy = transverse_obs(n)
    pubs = []
    for k in range(n_tr):
        isa = pass_manager.run(trotter_fid_circuit(offsets, couplings, k, dt_tr))
        pubs.append((isa, ox.apply_layout(isa.layout)))  # <X> at time k
        pubs.append((isa, oy.apply_layout(isa.layout)))  # <Y> at time k
    res = est.run(pubs).result()
    return np.array(
        [res[2 * k].data.evs + 1j * res[2 * k + 1].data.evs for k in range(n_tr)]
    )

def trotter_spectrum(fid):
    sig = fid * np.exp(-times_tr / 1.0) if APODIZE_TROTTER else fid
    spec = np.abs(np.fft.fftshift(np.fft.fft(sig)))
    freq = np.fft.fftshift(np.fft.fftfreq(n_tr, dt_tr))
    return freq, spec

fid_tr = run_trotter(
